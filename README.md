# 🏏 IPL Player Analysis Dashboard

A Python-based IPL Player Analysis Dashboard that analyzes tournament, team, player, and match statistics using CSV datasets and NumPy.

This project was built to strengthen my Python programming, data analysis, and problem-solving skills while working with structured cricket data.

---

## 📌 Features

### 🏆 Tournament Dashboard
- Total Players
- Total Teams
- Team with Lowest Economy
- Team with Best Batting Average
- Team with Most Wickets
- Top 5 Run Scorers
- Top 5 Wicket Takers

### 👥 Team Dashboard
- Total Team Runs
- Total Team Wickets
- Average Strike Rate
- Average Batting Average
- Average Economy
- Highest Run Scorer
- Highest Wicket Taker
- Team Squad

### 👤 Player Dashboard
- Top Run Scorer
- Top Wicket Taker
- Highest Batting Average
- Highest Strike Rate
- Most Catches

### 🔍 Search Dashboard
- Search Player
- Search Team
- Search Match
